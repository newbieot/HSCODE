Format Excel yang benar

Agar file terbaca dengan benar, siapkan satu baris header diikuti data barang. Satu baris = satu jenis barang.

Contoh format tabel CIPL dengan kolom No, Barang, Jumlah, Satuan, dan Hs Code
NoBarangJumlahSatuanHs Code
1Filter udara mesin kendaraan bermotor2PCS(kosong)
2Baju anak katun12PCS(kosong)
3Televisi LED 43 inch1UNIT(kosong)
  • 01
    Kolom wajib: "Barang"Header harus memuat kata Barang, Uraian, atau Description. Tanpa itu file ditolak.
  • 02
    Kolom "Hs Code" opsionalBila tidak ada, kolom baru otomatis dibuat. Kode yang sudah terisi tidak akan diubah.
  • 03
    Satu baris, satu jenis barangJangan menggabungkan banyak barang dalam satu cell. Tulis nama barang sejelas mungkin.
  • 04
    Barang di sheet pertamaData dibaca dari worksheet paling kiri pada file Anda.
  • 05
    Ragu? Pakai templateKlik "Unduh template" untuk file contoh yang sudah pasti terbaca sistem.
